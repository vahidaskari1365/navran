# ناوران | پلتفرم لجستیک امارات (Navaran Logistics)

پلتفرم مدیریت زنجیره لجستیک برای بازار **امارات متحده عربی** — مدیریت بار، حمل‌ونقل، ترکینگ، مانیتورینگ ناوگان و حسابداری.

> **بدون دیتابیس · بدون احراز هویت** — تمام داده‌ها در مرورگر شما (`localStorage`) ذخیره می‌شود و پنل با یک کلیک باز می‌شود.

---

## ✨ ویژگی‌ها

| ماژول | امکانات |
| --- | --- |
| مدیریت بار | تخته بار زنده، ثبت بار جدید، ثبت پیشنهاد نرخ، تبدیل بار به محموله |
| حمل و نقل | فهرست/فیلتر/جستجوی محموله‌ها، ثبت محموله با صدور خودکار کد رهگیری + بارنامه + فاکتور، تخصیص ناوگان و راننده، تایم‌لاین رویدادها |
| ترکینگ | صفحه عمومی رهگیری بدون ورود (`/track` و `/track/[code]`)، تایم‌لاین کامل رویدادها، ETA و پیشرفت مسیر |
| مانیتورینگ | نقشه زنده امارات، شبیه‌سازی پینگ تله‌متری (سرعت، سوخت، دمای یخچال)، هشدارها و بستن هشدار |
| حسابداری | فاکتور با VAT ۵٪، ثبت دریافتی، سن‌بندی مطالبات، ثبت هزینه، ترکیب هزینه‌ها و سود خالص |
| مشتریان | سقف اعتبار، مانده بدهی، مصرف اعتبار و پیوند به محموله‌های هر مشتری |

- رابط کاربری **فارسی و راست‌به‌چپ** با تاریخ شمسی و مبالغ به **درهم (AED)**
- طراحی تیره حرفه‌ای بر پایه **Next.js 16 (App Router) + Tailwind CSS 4**
- داده نمونه اولیه: ۳۶ محموله در ۶ ماه، ۱۰ مشتری، ۱۲ خودرو، ۱۰ راننده، ۳۵ فاکتور، ۹ بار
- دکمه **بازنشانی داده‌های نمونه** در سایدبار برای بازگرداندن وضعیت اولیه

## 🚀 اجرا

```bash
npm install
npm run dev
# http://localhost:3000
```

ساخت نسخه production:

```bash
npm run build
npm start
```

نیازی به PostgreSQL یا هیچ متغیر محیطی نیست.

## 🗺️ مسیرها

| مسیر | توضیح |
| --- | --- |
| `/` | وب‌سایت معرفی، ماژول‌ها، نقشه راه پایلوت امارات، پرسش‌های متداول |
| `/track` | صفحه رهگیری عمومی |
| `/track/NAV-7K42QD` | نمونه نتیجه رهگیری (کدهای دیگر: `NAV-3X77AT`، `NAV-0R55BQ`) |
| `/dashboard` | مرکز کنترل عملیات (بدون ورود) |
| `/dashboard/shipments` | مدیریت محموله‌ها و فیلترها |
| `/dashboard/shipments/new` | ثبت محموله جدید |
| `/dashboard/loads` | تخته بار و پیشنهاد نرخ |
| `/dashboard/monitoring` | مانیتورینگ ناوگان و هشدارها |
| `/dashboard/accounting` | فاکتورها، دریافتی‌ها و هزینه‌ها |
| `/dashboard/customers` | مشتریان و اعتبار |

## 🧱 معماری

```
src/
├── app/                 # صفحات (App Router) — همه سمت کلاینت
│   ├── page.tsx         # لندینگ
│   ├── track/           # رهگیری عمومی
│   ├── dashboard/       # مرکز کنترل
│   └── api/health/      # healthcheck بدون دیتابیس
├── components/          # کامپوننت‌های UI، نمودارها، فرم‌ها
└── lib/
    ├── types.ts         # مدل داده‌ها
    ├── seed.ts          # داده نمونه (تاریخ‌های نسبی)
    ├── selectors.ts     # محاسبات داشبورد/مالی/مشتریان
    ├── store.tsx        # Context + localStorage (بدون بک‌اند)
    └── format.ts        # اعداد، تاریخ شمسی، برچسب‌های وضعیت
```

**نکته:** داده‌ها فقط در مرورگر همان کاربر نگهداری می‌شوند؛ این نسخه برای نمایش و پایلوت است. برای محیط عملیاتی می‌توان لایه `store.tsx` را به API و پایگاه‌داده متصل کرد بدون تغییر صفحات.
